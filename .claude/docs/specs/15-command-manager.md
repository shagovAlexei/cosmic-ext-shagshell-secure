# 15. Command Manager

SecureCRT: Command Manager — дерево сохранённых команд (папки и команды), двойной щелчок отправляет команду в сеанс. У нас — панель справа от вкладок.

## Что видно
- View → «Менеджер команд» (галочка; запоминается): панель справа, ширина 260, с полем «Фильтр», деревом и кнопками «Команда +», «Папка +», «Изменить», «Удалить», «↑», «↓».
- Дерево: папки (раскрываются, вложенные папки можно) и команды в них и в корне. Строка команды: подпись (если пусто — первая строка текста).
- **Двойной щелчок / Enter / кнопка «Отправить»** — команда уходит в активный терминал (или во все вкладки, если у команды цель «Все вкладки»), как строка Button Bar (escapes `\r \n \t \e \p`). Реальный перевод строки в тексте = Enter (многострочные команды SecureCRT отправляют строку за строкой).
- «Команда +» / «Изменить»: подпись, текст (в одну строку, переводы строки — `\r`; из SecureCRT приходят настоящие), цель «Текущая вкладка / Все вкладки». «Папка +» / переименование папки — имя.
- Фильтр: подстрока в подписи или тексте без учёта регистра; совпавшие команды показываются вместе с папками, в которых лежат.
- Хранится в `~/.config/shagshell/commands.toml`: `[[folder]] name`, внутри `[[folder.command]]` (`label`, `text`, `target`) и вложенные `[[folder.folder]]`; команды в корне — `[[command]]`. Битый файл не перезаписывается (сообщение).

## Импорт из SecureCRT
File → «Импорт из SecureCRT…» получает третью галочку «Команды»: папка `Config/Commands` (`__Commands__.ini` — список ` SEND,текст,подпись,…`, тот же формат, что у Button Bar; `__FolderData__.ini` — порядок и вложенность папок). Уже существующие папки и команды (по имени папки и тексту) не дублируются, вложенность и порядок сохраняются. В реальном конфиге пользователя: 6 папок, ~40 команд. **Содержимое команд в репозиторий и в отчёты не попадает** (в них бывают пароли); тесты на синтетических данных.

## Мои решения (проверь)
- Управление кнопками над деревом, а не контекстным меню (контекстные меню в нашем дереве сессий пока не сделаны).
- Нет перетаскивания: порядок меняется стрелками ↑ ↓, перенос между папками — «Изменить» (выбор папки) позже, если понадобится; пока команду можно удалить и создать в нужной папке.
- Переменные в тексте (`%H` и т. п.) не раскрываются (в Button Bar они есть только у «Запустить программу»).
- Одна общая панель на все окна/сеансы; своего набора команд у сессии нет.

## Устройство
- `core::commands`: `Folder { name, commands, folders }`, корень = `Folder` без имени; `Commands::load/save`, `rows(filter, expanded) -> Vec<Row>` (видимые строки с путём-ключом), правки по пути (add/edit/remove/shift), `to_send(text)`; `securecrt::read_commands(dir)` — импорт.
- `app::command_manager`: панель, диалоги правки; отправка — `Tabs::send` как у Button Bar.
