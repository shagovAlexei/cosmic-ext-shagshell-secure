# 28. Pre-script сессии

Поле `pre_script` в файле сессии (Session Options → Connection → «Скрипт до подключения»).

## Что
- Запускается **до** ssh / telnet / оболочки, **без вкладки** (`crt.Screen.*` недоступен): можно спросить (`crt.Dialog`), поднять VPN, `ssh-add`, проверить хост (`os`, `subprocess`, `socket`). Аргументы: имя сессии, хост, пользователь.
- Закончился хорошо — вкладка открывается (и дальше запускается обычный `script` сессии). Упал, `sys.exit(1)` или остановлен — сессия **не открывается**, в строке состояния сообщение, ошибки в консоли скрипта.
- Работает там, где работает `script` сессии (двойной клик, Connect, Connect all, Quick Connect по сохранённой); не для Clone / Reconnect / «Открыть SFTP» (они не открывают сессию заново).
- Пример: `Example/14_pre_script.py`.

## Как
- `Session.pre_script` (+ `Form`, тесты trim / запись только непустого); `Scripts::run` отдаёт id запуска, `Outcome.ended`; `App.pre_runs` держит ожидающую вкладку (`Launch` и post-скрипт) до конца запуска.

## Не делаем
- Список скриптов на сессию; передачу результата pre-скрипта в сессию (например, выбранного хоста).
