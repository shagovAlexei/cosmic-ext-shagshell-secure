# 20. Проверка версии при запуске и поддержка проекта

## Что
- **При запуске** (в фоне, окно не ждёт) спрашиваем GitHub `releases/latest`. Новее нашей и не пропущена → окно «Доступна версия X (у вас Y)»: **Обновить** (открывает страницу релиза в браузере, там .deb), **Пропустить** (эта версия больше не предлагается, следующая — да), Esc / крестик = позже (спросим в следующий запуск). Сеть недоступна или лимит API — молча.
- **В том же окне** — кнопка «Поддержать проект» (Stripe Payment Link в браузере, как у shagoff-commander) и текст: «ShagShell Secure бесплатен. Если он вам помогает — поддержите проект: один обед в Маке или пара чашек кофе.» (en + ru).
- **Меню Help:** «Проверить обновления…» (ручная: показывает окно и для пропущенной версии, говорит «у вас последняя» или ошибку) и «Поддержать проект».
- **Global Options:** «Проверять обновления при запуске» (по умолчанию да). Пропущенная версия хранится в конфиге (`skipped_version`).
- Ничего не скачиваем и не ставим сами: обновление — страница релиза.

## Как
- `core::update` (из shagoff-commander): `field`, `newer`, `status`, `check` через `curl` (10 с), тесты.
- `app/updates.rs`: диалог и сообщения (`UpMsg`); проверка через `off_ui`; `DONATE_URL`.
- Иконка `heart.svg` в `res/icons/dialog` для окна.

## Открыто
- **`DONATE_URL`**: Payment Link отдельного Stripe-аккаунта проекта (как у shagoff-commander аккаунт «Shagoff Commander»). Аккаунт создаёт владелец (доступен только Fluent.lt); пока `DONATE_URL = None`, и кнопка доната, текст с просьбой и пункт Help скрыты; когда ссылка есть — `Some("https://donate.stripe.com/…")` одной строкой.
