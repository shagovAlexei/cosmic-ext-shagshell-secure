# 17. Шрифт терминала в Global Options

SecureCRT: Options → Session Options → Terminal → Appearance → Font. У нас шрифт один на все терминалы (Global Options), без привязки к сессии.

## Что
- **Options → Global Options → Terminal:** два поля — «Шрифт» (имя семейства, пусто = системный моноширинный) и «Размер» (пт, 6–48, по умолчанию 14).
- Применяется сразу ко всем открытым терминалам (`Tabs::restyle`) и к новым; хранится в cosmic-config (`font_family`, `font_size`).
- Ctrl+колесо / zoom по-прежнему меняет размер поверх выбранного (`zoom_adj`).
- Неизвестное имя семейства: cosmic-text откатывается на моноширинный шрифт сам; ошибку не показываем.

## Как
- `Style` получает `font_family: String`; `look()` берёт семейство и размер из `Config`. `terminal.rs` строит `Attrs` с `Family::Name(..)` или `Family::Monospace`; `set_config` пересчитывает ячейку при смене семейства.
- Размер зажимается в 6–48 при чтении конфига (чистая функция в `config.rs`, тест).

## Не делаем
- Выбор из списка установленных шрифтов (текстовое поле проще; список — по запросу).
- Шрифт на сессию.

## Проверка
- Тест: зажим размера. Headless: сменить размер → ячейки терминала растут без перезапуска; TESTING.md — ручная проверка шрифта.

## Что проверено
- Headless: `font_size=28`, `font_family="DejaVu Serif"` в конфиге → строки терминала по 40 px (28 × 1,4), шрифт сменился. Поля в Options проверяются вручную (клики по меню в headless не доходят).
