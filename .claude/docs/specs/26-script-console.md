# 26. Консоль скрипта и отладка

Сейчас вывод `print()` и ошибки Python уходят в файл `~/.local/state/shagshell/script.log`, а в строке состояния виден только последний его кусок. Писать и отлаживать скрипты неудобно.

## Что
- **Окно «Консоль скрипта»** (Script → Console, отдельное окно, как диалоги `crt`): живой вывод всех запусков.
  - Заголовок каждого запуска: `── 03_connect.py · 12:03:01 ──`, в конце: `── готово / остановлено / ошибка ──`.
  - Строки traceback и ошибки — цветом ошибки; номер строки скрипта виден как есть (Python его пишет).
  - Кнопки: **Стоп** (отменить текущий запуск), **Очистить**, **Копировать**, переключатель **Отладка**.
- **Открывается само** при ошибке скрипта и при первом `print()` запуска, если включено «Открывать консоль при выводе» (Global Options → Scripts, по умолчанию да). Закрыть можно в любой момент, запуск идёт дальше.
- **Режим отладки** (Script → Debug, помнится): каждый вызов `crt.*` пишется строкой `→ Screen.WaitForString("login:", 10000)` и результатом `← True`. Для `Dialog.Prompt` с `bPassword=True` и результатов паролей — `***`. Отладка идёт только в консоль, в файл не пишется (в строках могут быть введённые скриптом пароли).
- Файл `script.log` остаётся как был (0600), что видно в консоли — в него тоже идёт.

## Как
- `core::script`: `ConsoleBuf` (кольцо до 5000 строк, `push(run, kind, text)`, `since(n)`), `trace(call, args, result) -> String` (обрезает длинное, маскирует пароли). Тесты — сначала.
- `serve` получает флаг `debug` и вызывает `trace` для каждого запроса `crt`.
- app `script.rs`: stdout / stderr дочернего процесса — pipe, читает поток-надзиратель: строка → `script.log` + `ConsoleBuf`; окно опрашивает буфер по тику (как уже сделано для других окон), а не получает сообщение на каждую строку.
- `view_window` для окна консоли; `Scripts.console: Option<window::Id>`.

## Не делаем
- Пошаговый отладчик (breakpoints) и редактор скриптов.
- Интерактивный REPL.

## Проверка
- `just verify`; headless: скрипт с `print` и с ошибкой — консоль открылась сама, ошибка красная; Стоп останавливает `crt.Sleep(60000)`; Отладка показывает вызовы.
