# 12. Key Map: свои горячие клавиши

Tools → «Редактор клавиш…» (как Key Map Editor в SecureCRT): сочетание клавиш → действие. Действия те же, что у кнопок Button Bar: **Отправить строку** (с `\r \n \t \e \p`), **Функция меню**, **Запустить программу**, **Запустить скрипт** (то есть горячая клавиша на скрипт — главный повод). Сочетания глобальные (на все сессии).

## Как это выглядит
- Диалог со списком привязок «Сочетание · Действие · Описание» и кнопками «Добавить», «Изменить», «Удалить».
- «Добавить / Изменить»: кнопка «Нажмите сочетание…» (следующее нажатие записывается; Esc отменяет запись), описание (необязательно), вид действия и его поля — как в «Изменить кнопку» Button Bar.
- Хранится в `~/.config/shagshell/keymap.toml`: `[[key]] keys = "Ctrl+Alt+F5"`, `label`, `kind`, `arg`, `args`, `target`. Битый файл не перезаписывается (сообщение).

## Правила
- Сочетание — по физической клавише (работает в любой раскладке, как встроенные): `Ctrl` / `Alt` / `Shift` + клавиша. Допустимо: любая комбинация с Ctrl или Alt (кроме Ctrl+Insert / Shift+Insert, их занимает система, и кроме модификаторов самих по себе), и F1–F12 с любыми модификаторами или без.
- Не занятое встроенным (Alt+Q, Ctrl+Shift+T… — «уже занято: Быстрое подключение») и не занятое другой привязкой.
- Привязка сильнее терминала: нажатие не идёт в программу. Поэтому Ctrl+C / Ctrl+D / Ctrl+Z и т. п. занять нельзя (без этого не остановить программу): правило — **Ctrl и Ctrl+Shift с буквами и цифрами не допускаются**, остаётся Alt, Ctrl+Alt, F-клавиши, стрелки, Home / End / PgUp / PgDn с модификаторами.
- Нажатие работает, когда фокус в главном окне (в терминале, дереве); в полях ввода диалогов — нет (там это буквы).

## Мои решения (проверь)
- Один общий набор клавиш, не по сессиям (в SecureCRT есть и per-session — позже, если понадобится).
- Встроенные клавиши не переназначаются (только свои поверх свободных).
- Строка «Отправить строку» идёт на активную вкладку (цель «все вкладки» — как у кнопки).
