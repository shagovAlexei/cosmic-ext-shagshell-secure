# 45. Button Bar: полное меню кнопки, Button Manager, Button Bar Manager

Сейчас в меню кнопки (правый щелчок) — «Изменить…», «Влево», «Вправо»; в меню пустого места — «Новая / Переименовать / Удалить панель…», «Добавить кнопку…» (спека 25). В SecureCRT меню одно и полнее, плюс два окна-менеджера. Делаем как там.

## Меню

Одно и то же меню и у кнопки, и у пустого места панели (у пустого места пункты «про кнопку» серые). Сверху вниз:

| Пункт | Ключ `fl!` | Серый, когда |
|---|---|---|
| Новая кнопка… | `bb-add` (есть) | — (всегда в конец панели) |
| Изменить кнопку… | `bb-edit` (есть) | не на кнопке |
| Сдвинуть влево / вправо | `bb-left` / `bb-right` (есть) | не на кнопке; первая / последняя |
| Удалить кнопку | `bb-delete-button` | не на кнопке |
| Управление кнопками… | `bb-manager` | нет панели |
| — | | |
| Копировать кнопку | `bb-copy` | не на кнопке |
| Вставить кнопку | `bb-paste` | буфер пуст или нет панели |
| Копировать панель кнопок | `bb-copy-bar` | нет панели или в ней нет кнопок |
| — | | |
| Новая панель… | `bb-new-bar` (есть) | — |
| Переименовать панель… | `bb-rename-bar` (есть) | нет панели |
| Удалить панель | `bb-delete-bar` (есть) | нет панели |
| Дублировать панель… | `bb-duplicate-bar` | нет панели |
| Управление панелями… | `bb-bar-manager` | — |

**Любое удаление спрашивает подтверждение** (кнопка, панель; в меню и в обоих менеджерах): диалог «Удалить <имя>?» с «Удалить» / «Отмена».

## Буфер кнопок

- Свой, в памяти программы: `Vec<Button>`. Не системный буфер обмена — переносить между компьютерами есть резервная копия настроек (спека 38) и `buttonbars.toml`.
- «Копировать кнопку» кладёт одну кнопку, «Копировать панель кнопок» — все кнопки панели.
- «Вставить кнопку» вставляет всё из буфера после кнопки, по которой щёлкнули (с пустого места — в конец); в эту же или в другую панель. Буфер после вставки остаётся.
- «Дублировать панель…» — диалог имени (тот же, что у новой панели), по умолчанию «<имя> (копия)», «(копия 2)»… если занято; новая панель становится выбранной.

## Button Manager — «Управление кнопками…»

Окно-диалог «Button Manager — <имя панели>» (`bb-manager-title`).

```
┌ Button Manager — Local ─────────────────────┐
│ ┌─────────────────────────┐  [Изменить…]    │
│ │ ● ls -la                │  [Добавить…]    │
│ │ ● sudo -i          ◄sel │  [Копировать]   │
│ │   show run              │  [Вставить]     │
│ └─────────────────────────┘  [Удалить]      │
│        [↑] [↓]                              │
│                         [Отмена]  [OK]      │
└─────────────────────────────────────────────┘
```

- Список: цветной кружок (`dot_svg`) + подпись; щелчок выбирает.
- ↑ / ↓ — сдвинуть выбранную; «Изменить…» / «Добавить…» открывают окно Map Button поверх (тот же `Dialog::Map`, но правят черновик менеджера); «Копировать» / «Вставить» — общий буфер из меню; «Удалить» — с вопросом.
- Правка идёт в копии панели; OK записывает её в `bars` и сохраняет файл, Отмена выбрасывает. Буфер копирования живёт сам по себе (скопированное в отменённом менеджере остаётся в буфере).

## Button Bar Manager — «Управление панелями…»

Окно-диалог «Button Bar Manager» (`bb-bar-manager-title`).

- Список панелей (имя + число кнопок), ↑ / ↓ — порядок.
- Справа: «Добавить…» (диалог имени), «Изменить…» (Button Manager этой панели — правит тот же черновик), «Дублировать», «Переименовать…», «Удалить» (с вопросом).
- Под списком флажок «Сортировать по алфавиту» (`bb-sort`): ↑ / ↓ серые, список и все выборы панели (Button Bar, Session Options) — по имени без учёта регистра.
- Черновик — копия всех `Bars`; OK сохраняет и отдаёт приложению все переименования / удаления, чтобы сессии пошли следом (`relink` становится списком), Отмена выбрасывает.

## Core (`core::buttonbar`, тест сначала)

- `Bars.sort: bool` (`#[serde(default, skip_serializing_if = "not")]`, в начале файла `sort = true`); `Bars::names()` — в порядке файла или по алфавиту; приложение берёт порядок только отсюда.
- `Bars::move_bar(at, by)`, `Bars::duplicate(at, name) -> Result<usize, BarError>`, `Bars::copy_name(name) -> String` («<имя> (копия)», дальше «(копия N)»; само слово — параметр, его даёт `fl!`).
- `Bar::insert(after: Option<usize>, buttons: &[Button]) -> usize` (вставка после / в конец, индекс первой вставленной), `Bar::remove(i)`, `Bar::shift(i, by)` (перенести из `Bars::shift`).
- Переименования / удаления за сеанс менеджера: `fn relinks(before: &Bars, after: &Bars, renamed: &[(String, String)]) -> Vec<(String, Option<String>)>` — или менеджер копит их сам по ходу правки (выбрать на месте, что короче).

## App (`button_bar.rs`)

- Меню: один `Vec<menu::Item>` строится функцией от `Option<usize>` (кнопка или пустое место) — и для кнопок, и для `context_menu` пустого места.
- `Dialog::Buttons { bar, draft: Bar, sel: Option<usize> }`, `Dialog::Bars { draft: Bars, sel, renamed }`; Map Button и диалог имени над ними — вложенным полем (`under: Option<Box<Dialog>>`), чтобы после OK / Отмены вернуться в менеджер.
- `ButtonBar.clip: Vec<Button>`.
- Новые строки — в `i18n/en` и `i18n/ru`.

## Не делаем

- Системный буфер обмена (TOML) для кнопок — когда попросят.
- Перетаскивание мышью в списках — ↑ / ↓ хватает.
- Отдельное окно (свой `window::Id`) — диалог внутри главного окна, как Map Button.
