# 03. Сессии, Session Manager, Quick Connect, ssh

## Зачем

Главная функция SecureCRT: дерево сохранённых сессий, двойной клик открывает подключение во вкладке. Здесь появляются сессии, их хранение, дерево и запуск `ssh`. Пароли на этом этапе ssh спрашивает сам в терминале (keyring и askpass — этап 4).

Этап делится на два PR:
- **3a** — модель и хранилище сессий, запуск ssh, Session Manager (дерево, фильтр, мультивыбор, Connect all, перетаскивание, разделитель), Quick Connect, импорт `~/.ssh/config`, переименование / удаление / новая папка.
- **3b** — окно Session Options (как в SecureCRT) для новой сессии, правки и шаблона Default.

## Хранение (из архитектуры)

```
~/.config/shagshell/sessions/
  Default.toml              # шаблон (скрыт в дереве)
  prod/web-01.toml
  lab/cisco/sw-core.toml
```

- Id сессии — путь относительно `sessions/` без `.toml` (`prod/web-01`). Папки — каталоги.
- Поля (у всех есть default, лишние поля игнорируются — старые и будущие файлы читаются):

```toml
host = "10.0.0.1"          # обязательно
port = 2222                # нет — порт из ssh_config / 22
user = "admin"             # нет — из ssh_config / локальный
identity = "~/.ssh/id_ed25519"
keepalive = 30             # ServerAliveInterval, сек; нет — не задаём
extra = "-o Compression=yes"  # «Дополнительные параметры ssh», разбор как в shell
```

- Имя сессии/папки: не пустое, без `/`, не начинается с `.`, не `Default` в корне; совпадение в той же папке — ошибка «уже есть». Запись — через временный файл + rename (файл не портится при сбое).
- Новая сессия копирует `Default.toml` (если есть) и задаёт host.
- Состояние дерева (раскрытые папки) и ширина панели — в cosmic-config, переживают перезапуск.

## Запуск

`core::launch::ssh_argv(&Session, control_dir) -> Vec<String>`:

```
ssh [-p PORT] [-l USER] [-i IDENTITY] [-o ServerAliveInterval=N]
    -o ControlMaster=auto -o ControlPath=$XDG_RUNTIME_DIR/shagshell/%C -o ControlPersist=60
    [EXTRA…] HOST
```

- `$XDG_RUNTIME_DIR/shagshell/` создаётся при старте с правами 0700 (нет `XDG_RUNTIME_DIR` → `/tmp/shagshell-$UID`).
- `~` в identity раскрывается.
- Вкладка: заголовок — имя сессии (или `user@host` для Quick Connect без сохранения); программа задаёт свой — показывается её.
- Завершение / Reconnect / Enter — как на этапе 2, Reconnect запускает ту же команду заново. Строка статуса: «Подключено · SSH · host · cols×rows».
- Вкладка хранит, что запускать (`Launch { program, args, title, protocol }`); локальный shell — тоже `Launch`.

## Session Manager (3a)

```
┌ Session Manager ──────────────┐
│ [+сессия][+папка][✎][🗑][▶]   │
│ 🔍 [фильтр            ]       │
│ ▾ 📁 lab                      │
│   ▾ 📁 cisco                  │
│       🖥 sw-core              │
│ ▸ 📁 prod                     │
│   🖥 router                   │
└───────────────────────────────┘
```

- Дерево: папки первыми, затем сессии, по имени (без учёта регистра). ▸/▾ и двойной клик по папке раскрывают.
- **Фильтр**: подстрока в имени сессии или host, без учёта регистра; показывает подходящие сессии с их папками (раскрытыми). Esc очищает.
- **Выбор**: клик — одна строка; Ctrl+клик — добавить/убрать; Shift+клик — диапазон видимых строк.
- **Подключение**: двойной клик по сессии, Enter, кнопка ▶ или контекстное меню «Подключить» — все выбранные сессии; выбранная папка — все сессии в ней рекурсивно («Connect all»). Каждая — новая вкладка в активной группе.
- **Перетаскивание**: сессию или папку мышью на папку (или на пустое место — в корень). Нельзя в саму себя / в свою подпапку; конфликт имён — сообщение, ничего не двигается.
- **Контекстное меню** строки: Подключить, Переименовать…, Удалить…, Новая сессия…, Новая папка…; на пустом месте — две последние. Изменить… (окно Session Options) — в 3b.
- **Переименовать / Новая папка** — маленький диалог с полем ввода и проверкой имени. **Удалить** — подтверждение; для папки — «и N сессий внутри».
- **Разделитель** между панелью и вкладками тянется мышью (160…600 px), ширина сохраняется.
- Alt+C (Connect, как в SecureCRT) — показать Session Manager, если скрыт, и поставить фокус в фильтр.

## Quick Connect (3a)

Alt+Q и File → Quick Connect…, кнопка тулбара. Диалог:

```
Быстрое подключение
 Протокол:  SSH2
 Хост:      [            ]   Порт: [22  ]
 Пользователь: [          ]
 [ ] Сохранить сессию   Имя: [host]   Папка: [корень ▾]
                       [Отмена] [Подключить]
```

Хост обязателен; порт — число 1…65535 или пусто. «Сохранить сессию» создаёт файл (из Default) и выделяет его в дереве.

## Импорт ~/.ssh/config (3a)

File → Import from ~/.ssh/config: каждый `Host` без `*`, `?`, `!` → сессия `ssh config/<alias>` с `host = <alias>` и больше ничего — остальное (HostName, User, Port, ProxyJump, IdentityFile) ssh возьмёт из конфига сам при подключении. Уже существующие — пропускаются; итог — сообщение «Импортировано N, пропущено M». `Include` не разбираем.

## Session Options (3b)

Отдельное окно 760×540 «Параметры сессии — <имя>» (как в SecureCRT): слева категории, справа поля, внизу [Отмена] [OK].
- **Connection**: имя (только при создании), host, port, user.
- **SSH2**: identity (поле + «Обзор…» — файловый диалог), keepalive, дополнительные параметры ssh.
- Открывается: «Изменить…» в контекстном меню / кнопка ✎ / Options → Session Options… (для сессии активной вкладки), «Новая сессия…», Options → Edit Default Session….
- OK — проверка полей, запись; Cancel/закрытие окна — без изменений. Одновременно одно окно (повторный вызов поднимает его).

## Мои решения (проверь)

- Импорт `~/.ssh/config` сохраняет только alias: ssh сам применяет конфиг, и сессия не расходится с ним.
- Перетаскивание — внутри дерева (своё, мышью); из файлового менеджера / наружу — нет.
- Протокол пока только SSH2 (Telnet / Serial — этап 8), в файл поле `protocol` не пишем, появится со значением по умолчанию `ssh`.

## Не делаем

Пароли / keyring / askpass / Credentials (этап 4), jump host и пробросы в UI (этап 8), массовая правка сессий, экспорт.

## Проверка

- core-тесты: имена (валидные / недопустимые / дубликаты), store (создать из Default, загрузить дерево, переименовать, переместить, нельзя в подпапку, удалить папку, запись атомарная), `ssh_argv` (минимальная, все поля, `~`, extra с кавычками), импорт ssh_config (wildcards, несколько alias в одной строке, дубликаты, регистр `Host`), строки дерева (раскрытие, фильтр, диапазон Shift).
- headless: дерево с подготовленными файлами, фильтр, раскрытие, двойной клик → вкладка ssh (к `localhost` / тестовому серверу), мультивыбор + Enter → несколько вкладок, перетаскивание сессии в папку, разделитель, Quick Connect.
