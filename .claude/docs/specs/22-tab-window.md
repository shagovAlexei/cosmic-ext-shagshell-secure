# 22. Вкладка в отдельном окне

Терминал или SFTP-вкладка уходит в своё окно (второй монитор), **не перезапускаясь**: программа, вывод, лог, скрипты продолжают работать (как при переносе между группами, вкладка живёт в `Tabs.tabs` по id).

## Что
- **Меню вкладки → «Открыть в новом окне»** (и Window → то же для активной вкладки). Вкладка уходит из группы (опустевшая группа закрывается), открывается окно размером с главное, в нём только эта вкладка; заголовок окна = заголовок вкладки (следует за программой).
- **В окне:** строка заголовка с кнопкой **«Вернуть в главное окно»** и крестиком. **Крестик = вернуть вкладку**, а не убить программу (случайно закрытое окно ничего не теряет). Вернуть можно и через главное окно: Window → «Вернуть окна во вкладки».
- **Клавиши и действия:** то, что нажато / выбрано в окне вкладки, действует на эту вкладку (Ctrl+Shift+C / V, Reconnect, Command Window «в текущую», строка состояния главного окна показывает вкладку главного окна). События терминала идут по id, группы не нужны.
- **Скрипты:** `crt.GetTab(n)` видит и вкладки в отдельных окнах (после вкладок групп); `Tab.Activate` поднимает окно.
- **Закрытие главного окна** закрывает приложение, как раньше (с вопросом, если есть живые вкладки): отдельные окна закрываются вместе с ним.
- Состояние окон между запусками не хранится (открытые вкладки не восстанавливаются и сейчас).

## Как
- `Tabs.detached: Vec<(window::Id, TabId)>`; `TabCmd::Detach`, `Tabs::detach(id) -> Task` (отделить из модели группы, `window::open`), `Tabs::reattach(window)` (вставить в сфокусированную группу, `window::close`).
- `Tabs.front: Option<TabId>` — вкладка окна, из которого пришло событие; `active()`-подобные места берут её, если задана (`Tabs::active_id`). `App` ставит / снимает её по окну, из которого пришёл `Message::Input` / нажатие (`Input(w, ..)` из отдельного окна больше не отбрасывается).
- `App::view_window` для такого окна: `header_bar` + тело вкладки (`terminal_box` / `SftpView::view`), как в главном окне; `CloseRequested` → `reattach`.
- Чистой логики мало (порядок вкладок для скриптов — `order()` с отделёнными в конце); тест на него.

## Не делаем
- Перетаскивание вкладки мышью за пределы окна (в headless не проверить; меню даёт то же).
- Группы и несколько вкладок в отдельном окне; перенос вкладки из одного отдельного окна в другое (вернуть и отделить заново).
- Запоминание положения окон.

## Проверка
- Headless: вкладка через меню вкладки (клики по пунктам контекстного меню доходят) уходит в окно, ввод идёт в неё, вернуть — вкладка снова в группе, программа жива (тот же `$$` в shell). Крестик окна тоже возвращает.
