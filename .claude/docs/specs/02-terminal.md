# 02. Терминал, вкладки, группы вкладок

## Зачем

Сердце приложения — вкладка с терминалом. На этом этапе она запускает локальный shell; на этапе 3 та же вкладка запустит `ssh` (по архитектуре любое соединение — команда в PTY). Плюс группы вкладок (tiling) как в SecureCRT.

## Что видит пользователь

```
┌ File Edit View … ─────────────────────────────────────────────────────┐
│ Toolbar                                                               │
├──────────────┬────────────────────────────────┬───────────────────────┤
│ Session      │ [✓ Local Shell ×][✗ bash (2) ×]│ [✓ Local Shell (3) ×] │
│ Manager      │ $ ls                           │ $ top                 │
│              │                                │                       │
│              │   (группа 1)                   │   (группа 2)          │
├──────────────┴────────────────────────────────┴───────────────────────┤
│ Connected · Local Shell · 120×40                                      │
└───────────────────────────────────────────────────────────────────────┘
```

### Вкладки
- **File → New Local Shell** (Ctrl+Shift+T): новая вкладка в активной группе, `$SHELL` (запасной вариант `/bin/sh`) в домашнем каталоге, `TERM=xterm-256color`. Заголовок «Local Shell», повторные — «Local Shell (2)»…; если программа задала заголовок (OSC 0/2) — он.
- На старте окна вкладок нет — заглушка из этапа 1 (подсказка дополняется: «…или Ctrl+Shift+T — локальный shell»).
- Значок статуса слева от заголовка: ✓ (зелёный, процесс жив), ✗ (красный, процесс завершился).
- **Завершение процесса (как в SecureCRT):** вкладка остаётся со всем выводом, ✗, в терминал дописывается строка `[Process exited with code N — press Enter to restart]`; Enter (или Reconnect) запускает shell заново в этой же вкладке.
- Переключение: клик, Ctrl+Tab / Ctrl+Shift+Tab (по кругу в группе), Alt+1…Alt+9 (N-я вкладка группы).
- Закрытие: × на вкладке, средняя кнопка по вкладке, Ctrl+Shift+W. Если процесс жив — диалог «Закрыть вкладку „X“? Процесс будет завершён.» [Закрыть] [Отмена] (как SecureCRT «Confirm disconnect»). Завершённая — закрывается сразу.
- Порядок вкладок в группе — перетаскиванием в полосе вкладок.
- **Меню вкладки (ПКМ):** Reconnect (только для ✗), Clone (новый shell в той же группе), Move to New Group → Right / Down, Close.

### Группы вкладок (tiling, SecureCRT «Tab groups»)
- Окно делится на группы (`pane_grid`); у каждой своя полоса вкладок.
- **Window → Split Right / Split Down** (и «Move to New Group» в меню вкладки): текущая вкладка уходит в новую группу справа / снизу. Из группы с одной вкладкой — не доступно.
- Разделитель между группами тянется мышью.
- Активная группа — та, где последний клик/фокус; её вкладка получает ввод; рамка активной группы подсвечена акцентным цветом.
- Закрыта последняя вкладка группы → группа исчезает; закрыта последняя вообще → заглушка.
- Window → Next Tab / Previous Tab работают (как Ctrl+Tab).
- Перетаскивание вкладки между группами — в бэклог.

### Терминал
- Виджет и эмулятор из cosmic-term через shagoff-commander (`term/`), xterm-256color, true color, мышь, гиперссылки, IME.
- Прокрутка: 10 000 строк; колесо; Shift+PgUp/PgDn.
- Шрифт — моноширинный COSMIC, 14 px; цвета — палитра COSMIC тёмная/светлая по теме системы, меняется на лету.
- **Все Ctrl+буква и Alt+буква уходят в терминал**, кроме клавиш приложения ниже. Клавиши приложения: Ctrl+Shift+T/W/C/V, Ctrl+Tab, Ctrl+Shift+Tab, Alt+1…9, Alt+M.
- **Копирование / вставка:**
  - Ctrl+Shift+C — копировать выделение; Ctrl+Shift+V — вставить; Edit → Copy / Paste / Select All активны. Ctrl+Insert / Shift+Insert не занимаем: в системе пользователя на них другие функции (уходят в терминал как обычные клавиши).
  - **Копирование при выделении** (по умолчанию вкл.): отпустил мышь после выделения — текст в буфере обмена.
  - **Вставка средней кнопкой** (по умолчанию вкл.): вставляет буфер обмена.
  - Вставка — bracketed paste, если программа его включила.
- Размер терминала следует за окном и разделителями (SIGWINCH).

### Global Options (первая версия)
**Options → Global Options…** открывает боковую панель «Общие параметры», раздел «Терминал»:
- [x] Копировать при выделении
- [x] Вставлять средней кнопкой мыши

Сохраняются в cosmic-config, применяются сразу.

### Строка статуса
Для активной вкладки: «Подключено» / «Отключено», «Local Shell», `cols×rows`. Без вкладок — «Не подключено».

## Код

- `crates/app/src/term/` — копия `CMD/crates/app/src/term/{terminal,terminal_box,terminal_theme,mouse_reporter,style}.rs` с пометкой источника. Изменения:
  - `EventProxy` несёт `TabId`, события приходят как `(TabId, Event)`;
  - убрать `shell_pid`/follow и commander-специфичный `pass` (Ctrl+O);
  - `terminal_box`: флаги копирования при выделении и вставки средней кнопкой.
- `crates/app/src/tabs.rs` — модуль вкладок и групп: свой `Message`, `update`, `view`; `pane_grid::State<Group>`, у `Group` — `segmented_button` модель с `Tab` (терминал, заголовок, статус).
- `crates/app/src/options.rs` — боковая панель Global Options.
- `crates/core/src/tabs.rs` — чистая логика без UI, с тестами: нумерация заголовков («Local Shell (2)», свободный наименьший номер), порядок переключения (следующая/предыдущая по кругу, Alt+N за пределами → нет действия), выбор следующей активной вкладки после закрытия (соседняя справа, иначе слева), можно ли разделить группу.
- `crates/core/src/shell.rs` — выбор shell: `$SHELL`, если исполняемый, иначе `/bin/sh` (тесты).
- `menu::Action` пополняется: NewLocalShell, CloseTab, NextTab, PrevTab, SelectTab(u8), SplitRight, SplitDown, Copy, Paste, SelectAll, Reconnect (для локальной вкладки), GlobalOptions.
- Зависимости (как в commander): `alacritty_terminal = "0.25.1"`, `cosmic-text = { version = "0.19", features = ["monospace_fallback", "shape-run-cache"] }`, `indexmap = "2"`, `tokio` (rt, sync).

## Мои решения (проверь)

- Клавиши вкладок — Linux-терминальные Ctrl+Shift+T/W плюс SecureCRT-шные Ctrl+Tab и Alt+1…9. Точные дефолты SecureCRT для New/Close tab не проверены; переназначение клавиш — отдельная фича (Tools → Keymap Editor) позже.
- Alt+M остаётся у приложения (как Alt-ускорители в SecureCRT); в readline Meta-m при этом недоступен — переназначим, когда будет Keymap Editor.
- Перетаскивание вкладок между группами и вынос вкладки в новое окно — бэклог.
- Шрифт и размер шрифта в настройках — бэклог (этап 9 вместе со схемами цветов).

## Не делаем

Сессии, ssh, Find (Edit → Find остаётся неактивным), логирование, Command Window.
