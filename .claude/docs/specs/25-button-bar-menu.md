# 25. Button Bar: управление панелями правым кликом

Кнопки «New bar…», «Rename bar…», «Delete bar…» занимают место и мешают, когда кнопок много.

## Что
- В строке Button Bar остаются выпадающий список панелей (если их больше одной), кнопки и «+».
- **Правый клик по пустому месту панели** — меню: «Новая панель…», «Переименовать панель…», «Удалить панель…» (последние два недоступны, если панели нет), разделитель, «Добавить кнопку…».
- Правый клик по кнопке — как сейчас (Изменить / Удалить / Влево / Вправо).
- Диалоги те же (`BbMsg::NewBar / RenameBar / DeleteBar`), логика не меняется.

## Не делаем
- Перенос кнопок на вторую строку при переполнении (отдельно, если понадобится).

## Проверка
- `just verify`; headless: правый клик по пустому месту открывает меню, «Новая панель…» открывает диалог.
