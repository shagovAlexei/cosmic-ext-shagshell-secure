# 23. Command Window: многострочный ввод

Сейчас Command Window — одна строка (`text_input`): вставить или набрать несколько команд нельзя.

## Как у SecureCRT (vandyke.com/support/tips/chatsendcom.html)
- Команда уходит по **Enter**; **Ctrl+Enter** вставляет перевод строки — так готовят несколько строк до отправки.
- Вставленный многострочный текст остаётся в окне, пока не нажат Enter; тогда каждая строка уходит как команда + Enter.
- **Вверх / вниз** листают историю (размер истории — опция).
- Right-click: «Send commands to current / all / visible».

## Что
- Поле — многострочное (`text_editor`), растёт с текстом от 1 до 6 строк, дальше прокрутка.
- **Enter** — отправить, **Ctrl+Enter** (и Shift+Enter) — новая строка. Вставка (Ctrl+V) сохраняет переводы строк.
- Отправка: каждая **непустая** строка разбирается `core::macros` (`\r \t \e \p`) и завершается `\r`; последовательно, в порядке строк. Одна пустая строка (ничего не набрано) = голый Enter, как сейчас. Пустые строки внутри текста пропускаются (guess: SecureCRT шлёт и их; пропуск безопаснее для паролей/меню — скажи, если нужно слать).
- **Вверх / вниз** на первой / последней строке листают историю (в одной строке — как раньше). Запись истории = весь многострочный текст целиком; выпадающий список истории остаётся (многострочная запись показывается первой строкой + «…»).
- Кнопка «Отправить» и выбор адресата — без изменений.

## Как
- `core::macros::lines(text) -> Vec<Vec<Piece>>`: разбить по `\n` (и `\r\n`), пропустить пустые, каждой добавить `\r`; пустой текст → один `\r`. Тесты (core, TDD): одна строка, несколько, CRLF, пустые внутри, пустой, `\p` в строке.
- `CommandWindow`: `text: String` → `text_editor::Content`; `update` возвращает `Vec<Piece>` всех строк подряд (`\p` паузы внутри работают как раньше через `TabsMsg::Send`).
- Ключи: перехват Enter / Ctrl+Enter через `key_binding` текст-редактора.

## Не делаем
- Задержку между строками (line delay) — если понадобится, отдельной опцией.
- Режим «посимвольно» (интерактивный).
- Хранение истории на диске (там могут быть пароли).

## Проверка
- `just verify`; headless: набрать две строки через Ctrl+Enter, Enter → обе исполнились в shell; вставка нескольких строк.
