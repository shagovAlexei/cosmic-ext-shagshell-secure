# 07. Логирование сессий

Как в SecureCRT (Session Options → Log File, Global Options): имя из шаблона, запись при подключении, «дописывать / заново», «сырой» лог.

## Что и как
- **Шаблон имени** (`core::logfile::expand`): `%S` сессия, `%H` хост, `%P` порт, `%U` пользователь, `%Y %M %D` дата, `%h %m %s` время, `%%`. Значения безопасны для имени файла (`/` и управляющие → `_`). Относительное имя кладётся в папку логов (Global Options → «Логи», по умолчанию `~/ShagShellLogs`), `~/…` и абсолютное — как есть. Папки создаются.
- **Сессия** (Session Options → «Файл лога», поля `log_file` / `log_append` / `log_raw` в файле сессии): непустое имя — лог пишется с момента подключения (и при Reconnect — в новый файл по шаблону, т.к. время другое). Пусто — лога нет.
- **Вручную:** File → «Записывать лог сессии» (галочка) включает / выключает лог активной вкладки; имя — по шаблону сессии, а у вкладки без него (локальный shell, быстрое подключение) — по шаблону из Global Options. В статус-баре «● ЗАПИСЬ».
- **Что пишется:** вывод PTY, тот же, что видит терминал (то, что набираешь, возвращается эхом). По умолчанию текст: escape-последовательности убраны, `\r` возвращает к началу строки (перезапись, как у прогресс-бара), backspace, `ESC[K`. «Сырой лог» — байты как пришли. Строка уходит в файл целиком по `\n`, недописанная — при остановке.
- Не получилось открыть файл / запись оборвалась (диск) — сообщение в строке состояния, лог выключается, вкладка работает.

## Устройство
- `core::logfile` — шаблон, `Cleaner` (автомат), `Logger`; тесты.
- `app::term::log` — `Tap` (общий `Logger` за мьютексом) и `TeePty`: обёртка над `tty::Pty`, у которой читатель — второй дескриптор того же мастера и копирует прочитанное в лог; цикл событий alacritty о ней не знает.

## Мои решения (проверь)
- Только вывод, без «лога ввода» и без отметок времени на строках (в SecureCRT они опциональны).
- Курсорные перемещения (`ESC[C`, `ESC[D` и др.) в текстовом логе не разбираются: у zsh с автодополнением (подсказки серым) строка с подсказкой может попасть в лог «склеенной»; для точной записи есть сырой лог.
- Лог в память не копится: пишется сразу; ротации по размеру / дню нет (имя с `%D` даёт файл на день при новом подключении).
