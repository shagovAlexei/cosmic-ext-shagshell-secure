# 06. Command Window и Button Bar

Этап делится на два PR:
- **6a** — Command Window (этот документ).
- **6b** — Button Bar (раздел 5 в `00-architecture.md`): именованные панели, Send String / Menu Function / Launch App, панель на сессию.

## 6a: Command Window

- View → Command Window (галочка; `Config.command_window_visible`, по умолчанию выключено): строка под терминалами — поле ввода, список «история» (после первой отправки), выбор цели, кнопка «Отправить».
- Enter (или «Отправить») шлёт строку и `\r`. Пустая строка — просто `\r`.
- Escape-последовательности как у Send String в SecureCRT (`core::macros`): `\r \n \t \e \\`, `\p` — пауза 1 с; другой `\x` остаётся как набран.
- Цель: **Текущая вкладка** (по умолчанию) / **Видимые вкладки** (передняя вкладка каждой группы) / **Все вкладки**. Получают только терминалы с живой программой; SFTP-вкладки и завершённые пропускаются.
- История — до 100 строк, подряд идущие повторы не дублируются, выбор кладёт строку в поле (не отправляет). **Только в памяти**: в поле могут набрать пароль, а секреты в файлы не пишем.
- Клик в поле забирает клавиши у терминала (иначе набранное шло бы и туда).
- Пауза `\p`: часть до неё уходит сразу, остаток — через секунду (сообщение `TabsMsg::Send`), вкладки в процессе не блокируются.

### Мои решения (проверь)
- Цель не запоминается между запусками; история не сохраняется.
- Отдельной горячей клавиши нет (SecureCRT тоже не даёт по умолчанию).
