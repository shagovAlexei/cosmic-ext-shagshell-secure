# 06. Command Window и Button Bar

Этап делится на два PR:
- **6a** — Command Window (этот документ).
- **6b** — Button Bar (раздел 5 в `00-architecture.md`): именованные панели, Send String / Menu Function / Launch App, панель на сессию.

## 6a: Command Window

- View → Command Window (галочка; `Config.command_window_visible`, по умолчанию выключено): строка под терминалами — поле ввода, список «история» (после первой отправки), выбор цели, кнопка «Отправить».
- Enter (или «Отправить») шлёт строку и `\r`. Пустая строка — просто `\r`.
- Escape-последовательности как у Send String в SecureCRT (`core::macros`): `\r \n \t \e \\`, `\p` — пауза 1 с; другой `\x` остаётся как набран.
- Цель: **Текущая вкладка** (по умолчанию) / **Видимые вкладки** (передняя вкладка каждой группы) / **Все вкладки**. Получают только терминалы с живой программой; SFTP-вкладки и завершённые пропускаются.
- История — до 100 строк, подряд идущие повторы не дублируются, выбор кладёт строку в поле (не отправляет). **Только в памяти**: в поле могут набрать пароль, а секреты в файлы не пишем.
- Клик в поле забирает клавиши у терминала (иначе набранное шло бы и туда).
- Пауза `\p`: часть до неё уходит сразу, остаток — через секунду (сообщение `TabsMsg::Send`), вкладки в процессе не блокируются.

### Мои решения (проверь)
- Цель не запоминается между запусками; история не сохраняется.
- Отдельной горячей клавиши нет (SecureCRT тоже не даёт по умолчанию).

## 6b: Button Bar

Как в `00-architecture.md`, раздел 5; уточнения:
- View → Button Bar (галочка, по умолчанию включена): строка внизу, под Command Window. Слева выбор панели (если их больше одной), кнопки, «+» (новая кнопка), справа «Новая / Переименовать / Удалить панель…».
- Кнопка: **Send String** (`core::macros`, цель Текущая / Все вкладки), **Menu Function** (13 функций приложения: `menu::NAMED`), **Launch Application** (`%H %P %U %S` из сессии активной вкладки, без shell: слова по `shlex`).
- ПКМ по кнопке: Изменить… / Удалить / Сдвинуть влево / вправо. Окно «Настройка кнопки» — внутри окна приложения.
- Первая кнопка создаёт панель «Основная», если панелей нет.
- Сессия может выбрать свою панель (Session Options → «Панель кнопок», поле `button_bar` в файле сессии); пока её вкладка впереди, показывается она, иначе выбранная на панели. Только ssh-сессии (у вкладки «локальный shell» сессии нет).
- Файл `~/.config/shagshell/buttonbars.toml` (`[[bar]] name`, `[[bar.button]] label kind arg target`); **битый файл не перезаписывается** (ошибка в строке состояния, правки не сохраняются).
- Run Script — в фазе 10.
### Мои решения (проверь)
- Menu Function всегда про текущую вкладку (цель только у Send String).
- Нет клавиш на кнопки (SecureCRT даёт «Map Button → Hot key», позже вместе с Key Map).
- Известное ограничение: пока впереди вкладка сессии со своей панелью, выбрать другую в выпадающем списке нельзя (показывается панель сессии); «Переименовать / Удалить» тоже про неё. Сессии, называвшие переименованную / удалённую панель, следуют за ней (`Store::relink_bar`).
