# 31. Заметки (Note)

Простое текстовое окно рядом с терминалами: шпаргалка с командами и подсказками, свои записи. Ветка `feat/notes` (от `feat/scheduler`), версия 0.42.0.

## Что
- **Окно заметок** (отдельное окно, как Планировщик): View → «Заметки» (и действие `Notes` для клавиши в Keymap Editor). Одно окно; повторный вызов поднимает его.
- Текст — многострочный редактор; **автосохранение** в файл через ~1 с после последней правки и при закрытии.
- Первая заметка — `~/.config/shagshell/notes/Заметки.md` (создаётся при первом открытии) с **шпаргалкой**: клавиши приложения, команды ssh (`~/.ssh/config`, `-J`, `-L`), заготовки `crt`-скриптов, подсказки по Cisco / MikroTik. Текст en / ru по языку интерфейса; свои правки не затираются.
- **Переименовать** — кнопка в шапке окна: переименовывает файл (имя проверяется как имя сессии; повтор — ошибка).
- **Открыть файл…** — любой текстовый файл или `.md` (диалог выбора файла, помнит папку); в окне один файл, предыдущий сохраняется. Бинарный / не UTF-8 / больше 5 МБ — отказ с сообщением.
- **`.md` → предпросмотр** (заголовки, списки, код, ссылки, жирный / курсив); маленькая кнопка «правка ↔ просмотр» в шапке окна. Для `.md` по умолчанию открывается просмотр; для остальных — правка.
- **Тумблер** Options → Global Options: «Открывать заметки при запуске» (по умолчанию выкл.); открытый в конце файл запоминается (`notes_file`).

## Как
- `core::notes`: `dir()`, `ensure_default(lang) -> PathBuf` (создаёт файл со шпаргалкой, если его нет), `read(path) -> Result<String, ReadError>` (размер, UTF-8), `rename(path, name) -> io::Result<PathBuf>` (имя через `session::store::check_name`, расширение `.md` сохраняется), `is_markdown(path)`; тесты на всё.
- App: `notes.rs` (`NoteWindow`, `NoteMsg`: `text_editor::Content`, режим, отложенное сохранение подпиской-таймером); просмотр — `cosmic::widget::markdown` (feature `markdown` у libcosmic); выбор файла — `portal` из `script.rs`; Config: `notes_on_start: bool`, `notes_file: String`.
- Строки `fl!` en+ru, TESTING.md, раздел в `CLAUDE.md`.

## Не делаем
- Несколько заметок во вкладках / список файлов (один файл в окне; «Открыть…» переключает);
- WYSIWYG-редактирование markdown, поиск по тексту, синхронизацию;
- Вставку выделенного из заметки в терминал (можно позже: кнопка «Отправить строку»).
