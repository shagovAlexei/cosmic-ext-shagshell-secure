# 31. Заметки (Note)

Простое текстовое окно рядом с терминалами: шпаргалка с командами и подсказками, свои записи. Ветка `feat/notes` (от `feat/scheduler`), версия 0.42.0.

## Что
- **Заметка — вкладка**, как открытая сессия: в той же полосе вкладок и группах, закрывается ×, её можно перенести в своё окно (Move to new window) и разделить панель. Значок вкладки ✎. Reconnect / Clone / SFTP для неё недоступны.
- Открыть: View → «Заметки» (действие `Notes` для клавиши): открывает или показывает вкладку главной заметки. File → «Открыть заметку…» и кнопка «Открыть…» в самой вкладке — любой текстовый файл или `.md` (диалог выбора файла, помнит папку), каждый файл в своей вкладке; уже открытый — показывается.
- Вкладка: сверху полоска (имя файла, кнопки «Переименовать», «Открыть…», для `.md` — «правка ↔ просмотр»), ниже многострочный редактор. **Автосохранение** через ~1 с после правки и при закрытии вкладки / приложения.
- Главная заметка — `~/.config/shagshell/notes/Заметки.md` (создаётся при первом открытии) со **шпаргалкой**: клавиши приложения, ssh (`~/.ssh/config`, `-J`, `-L`), заготовки `crt`-скриптов, подсказки по Cisco / MikroTik. Текст en / ru по языку интерфейса; правки не затираются.
- **Переименовать** переименовывает файл (имя как у сессии; расширение сохраняется; повтор — ошибка).
- Бинарный / не UTF-8 / больше 5 МБ — отказ с сообщением.
- **`.md` → предпросмотр** (заголовки, списки, код, ссылки, жирный / курсив); для `.md` вкладка открывается в просмотре, для остальных — в правке.
- **Тумблер** Options → Global Options: «Открывать заметки при запуске» (по умолчанию выкл.). Какие файлы были открыты заметками, запоминается (`notes_open`), при запуске с тумблером они открываются вкладками.

## Как
- `core::notes`: `dir()`, `ensure_default(lang) -> PathBuf` (создаёт файл со шпаргалкой, если его нет), `read(path) -> Result<String, ReadError>` (размер, UTF-8), `rename(path, name) -> io::Result<PathBuf>` (имя через `session::store::check_name`, расширение `.md` сохраняется), `is_markdown(path)`; тесты на всё.
- App: `notes.rs` (`NoteView`, `NoteMsg`: `text_editor::Content`, режим), `tabs::Body::Note` (`Launch.note: Option<PathBuf>`), отложенное сохранение — таймер раз в секунду, пока есть несохранённое; просмотр — `core::mdview` (markdown → текст + вид каждого куска) в read-only `text_editor` с подсветкой, текст выделяется мышью (ссылки не кликаются, адрес виден в скобках); выбор файла — `portal` из `script.rs`; Config: `notes_on_start: bool`, `notes_open: Vec<String>`.
- Строки `fl!` en+ru, TESTING.md, раздел в `CLAUDE.md`.

## Не делаем
- Список / поиск по заметкам;
- WYSIWYG-редактирование markdown, поиск по тексту, синхронизацию;
- Вставку выделенного из заметки в терминал (можно позже: кнопка «Отправить строку»).
