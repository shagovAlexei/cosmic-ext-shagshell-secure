# 16. Перенос вкладок между группами

Вкладка (терминал или SFTP) переходит в другую группу `pane_grid` **целиком, не перезапускаясь**: программа, вывод, лог, скрипты продолжают работать (вкладка живёт в `Tabs.tabs` по своему id, группа держит только ссылку).

## Как
- **Меню вкладки:** «Перенести в группу — слева / справа / сверху / снизу» (показываются только те стороны, где рядом есть группа). Работает всегда, проверено вживую.
- **Перетаскивание:** вкладку берут мышью и бросают на панель вкладок другой группы (на вкладку) или на тело другой группы. libcosmic этого ревизии шлёт в перетаскивании один байт «вкладка» без указания какая, поэтому «перетаскиваемой» считается вкладка, нажатая последней (нажатие её и активирует). Внутри своей панели перетаскивание остаётся перестановкой.
- Если группа опустела, она закрывается; перенесённая вкладка активна, фокус на новой группе.

## Не сделано
- **В новое окно.** Нужно второе окно со своей сеткой групп и перенос терминалов между окнами; отложено в бэклог (меню «Перенести в новую группу» даёт тот же эффект внутри окна).

## Что проверено
- Меню (headless, клики по пунктам контекстного меню доходят): вкладка из правой группы ушла в левую, правая закрылась, терминал остался жив и принимает ввод.
- Перетаскивание мышью в headless не воспроизводится (нет Wayland DnD от виртуального указателя): остаётся на ручной проверке.
