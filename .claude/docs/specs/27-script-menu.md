# 27. Меню Script: список скриптов, недавние, папка, скрипт при запуске

## Что
- **Script → Scripts** — подменю со скриптами (`*.py`, не скрытые, по имени, до 60) из папки скриптов; клик запускает на активной вкладке. Папка по умолчанию `~/.config/shagshell/scripts`, меняется: **Script → Choose scripts folder…** или Global Options → Scripts. Список читается при старте, после выбора папки, сохранения записанного скрипта и по **Script → Refresh the list**.
- **Script → Recent** — последние 10 запущенных из меню Run… / Scripts / Recent (новый сверху, без повторов).
- **Run… и сохранение записи открываются в папке последнего скрипта** (`Config.script_dir`), а пока её нет — в папке скриптов. Скрипт можно взять из любой папки. libcosmic не передаёт порталу стартовую папку, поэтому диалог — свой запрос к `ashpd` (`current_folder`).
- **Скрипт при запуске** (Global Options → Scripts): путь; программа открывает локальную оболочку и запускает его, как `--script`. Флаг `--script` сильнее.

## Не делаем
- Подпапки как подменю; горячие клавиши на пункты (для этого Key Map → Run Script).

## Проверка
- `just verify` (тесты `list_dir`, `recent_push`); headless: меню рисуется, стартовый скрипт выполняется. Подменю и диалоги — вручную.
