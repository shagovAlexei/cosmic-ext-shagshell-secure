# 24. Боковые панели: сторона и порядок

Session Manager всегда слева, Command Manager всегда справа. Нужно: поменять местами, поставить обе с одной стороны.

## Что
- Две настройки в Options → Global Options: **«Session Manager: слева / справа»** и **«Command Manager: слева / справа»** (`Side::{Left, Right}`; умолчание как сейчас: SM слева, CM справа).
- Любое сочетание: поменять местами (SM справа, CM слева), обе слева, обе справа.
- Если обе с одной стороны, **Session Manager внешний** (у края окна), Command Manager рядом с терминалом (guess; скажи, если нужно иначе).
- Размеры и видимость (View) не меняются; разделитель Session Manager тянется в нужную сторону (справа — вправо ширина уменьшается).
- Применяется сразу, хранится в cosmic-config.

## Как
- `config.rs`: `session_manager_side`, `command_manager_side: Side` (serde default).
- `App::view`: собрать `left` и `right` ряды по настройкам: `[SM?, CM?] | центр | [CM?, SM?]`.
- `session_manager.rs`: знак перетаскивания разделителя от стороны.
- Логика порядка — чистая функция `panels(sm_side, cm_side, sm_vis, cm_vis) -> (Vec<Panel>, Vec<Panel>)` в `core` или app-модуле с тестом (все 4 сочетания).

## Не делаем
- Перетаскивание панели мышью на другую сторону (только настройка).
- Панели сверху / снизу.

## Проверка
- `just verify`; headless: поменять стороны в Global Options → панели на местах; обе слева — SM у края.
