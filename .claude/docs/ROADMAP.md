## Бэклог

- Flatpak
- Редактирование удалённого файла локально (SecureFX «Edit»)
- Command Manager (дерево сохранённых команд)
- Импорт Button Bar из SecureCRT: кнопки Menu Function / Launch App (в настоящих файлах не встретились, формат строк неизвестен)
- Перетаскивание вкладки между группами и в новое окно
- Шрифт и его размер в Global Options
- Запись скрипта (Script → Start Recording)

Не делаем: SSH1, RLogin, TAPI, TN3270/5250, VBScript/JScript, legacy-эмуляции.
- Улучшения скриптинга:
  - Примеры скриптов в папке `Example/` на разные ситуации: открытие сессии, подключение к одному и нескольким хостам, выполнение команд, разбор их вывода, результат в буфер обмена и в файл и т. д. Образцы взять из папки со скриптами SecureCRT (только чтобы понять, какие задачи решают: чужие хосты, пути и пароли в репозиторий не переносить).
  - В примерах подробные комментарии на русском и английском (что делает каждый шаг и чем отличается от SecureCRT).
  - Для примеров понадобится недостающее в `crt`: буфер обмена (`crt.Clipboard.Text`), чтение экрана по координатам (`Screen.Get`), `Session.Log`, ожидание нескольких строк с таймаутом и т. п. — выяснить по примерам.
