## Бэклог

Не делаем: Flatpak (2026-10-25). Программа запускает системные ssh / telnet / picocom / python3 / lrzsz, читает `/proc/<pid>/environ` и сокеты в `$XDG_RUNTIME_DIR`; в песочнице это или `flatpak-spawn --host` без песочницы, или всё внутри пакета без `~/.ssh` и агента. Пакет — `.deb` с SHA256SUMS.

## Замечания после ручной проверки (не исправлено, ждёт решения)

Интерфейс:
- [x] SFTP-вкладка: нарисовать кнопки F-клавиш как в shagoff-commander (вместо текстовой подсказки внизу).
- [x] Строка состояния выше Button Bar.
- [x] Высота кнопок Button Bar — в настройках.
- [x] Высота заголовков вкладок — в настройках.
- [x] Консоль скрипта — вкладка справа, а не отдельное окно.

Button Bar:
- [x] Нельзя переключиться на другую панель (выбор панели из самого бара).
- [x] Кнопку нельзя переименовать.
- [x] Кнопка «Запустить скрипт»: выбор `.py` через диалог выбора файла (сейчас путь вводится руками).
- [ ] После «Импорт из SecureCRT…» с Button Bar что-то сломалось (симптом уточнить: проверить кнопки RUN с `.py`, путь под `~/.wine/drive_c/…`, отчёт «не импортировано»).

Планировщик:
- [x] Русские подписи кнопок обрезаются / не видны (нижний ряд: «Запустить сейчас», «Удалить», «Сохранить»).
- [x] Скрипт выбирать через диалог выбора файла.
- [x] Выключенное задание в списке — другим цветом, чем включённое.

Заметки:
- [x] В режиме просмотра `.md` нельзя выделять текст мышью (просмотр теперь read-only редактор с подсветкой: выделение и Ctrl+C работают; кнопка «Копировать всё»).
- [ ] «Шрифт…» в меню вкладки заметки (семейство и размер), масштаб Ctrl+= / Ctrl+− / Ctrl+0, поиск по тексту (Ctrl+Shift+F сейчас ищет только в терминале).
- [ ] Поиск и замена, как в COSMIC Edit: перенести его `src/search.rs` (pop-os/cosmic-edit), как перенесены `text_box.rs` / `line_number.rs` в `crates/app/src/editor/`.

Окно:
- [ ] «Always on Top» (поверх всех окон).
- [ ] Скрытие главного меню отдельной клавишей (сейчас меню прячется только в полноэкранном режиме F11).

Параметры сессии:
- [x] «Скрипт до подключения» и «Скрипт при открытии сессии»: диалог выбора файла.
- [ ] Скрипт при открытии сессии ждёт приглашения `crt.Screen.WaitForString("$")`; что делать, если такого приглашения нет (таймаут, другой промпт)? Решить поведение.


Вторая порция замечаний (не исправлено):
- [ ] Этап 14 (X / Y / Zmodem): не проверено.
- [ ] Перетаскивание вкладки в другую группу (на вкладку или на терминал): на локальном терминале не работает (нужна отладка на живом рабочем столе: `RUST_LOG=trace`, цель libcosmic `tab_reorder`; в headless не воспроизвести; пока есть пункт «Переместить» в меню вкладки).
- [ ] SFTP-вкладка не перетаскивается между группами.
- [x] В диалоговых окнах скриптов нет значков.
- [x] Ctrl+колесо по-прежнему масштабирует поверх выбранного размера шрифта.
- [x] Шрифт терминала: выбор из списка установленных (как в SecureCRT), а не ввод имени руками; размер шрифта тоже выбором.
- [x] Global Options: поля ввода (шрифт, папка логов, папка Zmodem, папка скриптов, скрипт при запуске) сжаты в узкие рамки, текст не виден; строки меню не помещаются по ширине (подписи обрезаны, переключатель Zmodem вылезает за край).

Не делаем: SSH1, RLogin, TAPI, TN3270/5250, VBScript/JScript, legacy-эмуляции.
