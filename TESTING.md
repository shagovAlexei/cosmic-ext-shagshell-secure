# Тестирование

`just verify` = `cargo fmt --check` + `clippy -D warnings` + `cargo test`. Его запускаем перед каждым PR, CI запускает его же.

## Подготовка к ручной проверке

Общие действия, на которые ссылаются пункты ниже.

- **Тестовый сервер:** сессия SSH на `home@192.168.0.20` (вход по ключу). Создать: Менеджер сессий → кнопка «Новая сессия» → Протокол SSH2, хост `192.168.0.20`, пользователь `home` → Сохранить. Дальше она называется «тестовая сессия».
- **Локальная оболочка:** Ctrl+Shift+T (или Файл → «Новый локальный shell»).
- **Запустить скрипт:** откройте вкладку с терминалом (локальную или тестовую сессию), затем меню «Сценарий → Запустить…» и выберите файл `.py`. Скрипт работает с активной вкладкой.
- **Примеры скриптов:** папка `Example/` в репозитории (программа при запуске кладёт их в `~/.config/shagshell/scripts/examples/`). В начале каждого файла по-русски написано, что он делает.
- **Свой маленький скрипт:** создайте файл, например `~/t.py`, вставьте строки из пункта и запустите, как сказано выше.
- **Вывод скрипта** (`print`, ошибки) виден в «Сценарий → Консоль».
- **Файлы настроек:** `~/.config/shagshell/` (сессии, кнопки, клавиши, планировщик, заметки).
- **Общие параметры:** меню «Параметры → Общие параметры…» открывает панель справа; нужная настройка ищется по подписи, указанной в пункте.

### Конструктор: запуск с подсветкой и отладка (v0.89.0)
Подготовка: скрипт `~/.config/shagshell/scripts/templates/dbg.py` из пяти строк:
```python
x = 1
for i in range(3):
    x = x + i
crt.Sleep(1500)
done = True
```
- [ ] **Подсветка выполнения** (v0.89.0)
  1. Откройте вкладку локального shell. «Сценарий → Конструктор скриптов…», «Из шаблона ▾» → `templates · dbg`.
  2. Нажмите «Запустить» и смотрите на ленту.
  - Должно быть: пока идёт `Sleep`, его блок обведён синей рамкой, уже пройденные блоки — зелёные; вместо «Запустить» — кнопки «Пауза», «Шаг», «Стоп»; после конца все блоки зелёные, снова «Запустить», внизу «Сценарий завершён». Первая правка любого поля убирает подсветку.
- [ ] **Точка остановки, переменные, шаг** (v0.89.0)
  1. Щёлкните кружок ○ слева от блока `x = x + i` (внутри «для каждого») — он станет красным ●.
  2. «Запустить».
  3. Нажмите «Продолжить» (▶) ещё раз.
  4. Нажмите «Шаг» (>) два раза.
  5. Щёлкните красную точку (снимите её) и нажмите «Продолжить».
  - Должно быть: в шаге 2 запуск встаёт на этом блоке (оранжевая рамка), под палитрой «Переменные: x = 1, i = 0», на блоках `x = …` их значения; в шаге 3 встаёт снова с `i = 1`; в шаге 4 каждый «Шаг» переходит на следующую строку; в шаге 5 скрипт доходит до конца.
- [ ] **Ошибка в скрипте** (v0.89.0)
  1. Соберите `x = 1`, затем «Переменная» `y` = `x + nope`, затем ещё любой блок. «Запустить».
  - Должно быть: блок `y = x + nope` с красной рамкой и текстом `NameError: name 'nope' is not defined…` на нём; блоки после него не зелёные; Script Console показывает ту же ошибку.
- [ ] **Стоп и отключение** (v0.89.0)
  1. Поставьте `Sleep` на 30000, запустите, нажмите «Стоп».
  2. ⚙ рядом с «Запустить»: снимите обе галочки, запустите снова.
  - Должно быть: «Стоп» останавливает сразу (внизу «Сценарий остановлен»); в шаге 2 скрипт идёт без подсветки и без кружков точек, как обычный запуск из меню.
- [ ] **Открытый файл со своей разметкой, ветки** (v0.89.0)
  1. Создайте `~/.config/shagshell/scripts/layout.py`, сохраните, не трогая отступы и пустые строки:
     ```python
     x = 1


     if x == 2:
         y = 2
     elif x == 1:   # ветка
         y = 3
     try:
         z = x + nope
     except NameError:
         z = 0
     crt.Sleep(500)
     ```
  2. «Сценарий → Открыть в конструкторе…» → `layout.py`. Ничего не правьте, поставьте ● на блок `crt.Sleep`, «Запустить».
  3. «Продолжить».
  - Должно быть: встаёт ровно на `crt.Sleep` (оранжевая рамка), переменные `x = 1, y = 3, z = 0`; зелёные `x = 1`, `if`, `y = 3`, `try`, `z = x + nope` (выполнялся, ошибку поймал `except`), `z = 0`; блок `y = 2` не зелёный (эта ветка не выполнялась).
- [ ] **Только точки, без подсветки; закрытие на паузе** (v0.89.0)
  1. ⚙: снимите «Подсвечивать блоки», оставьте «Останавливаться на точках». Скрипт `dbg.py`, ● на `x = x + i`, «Запустить».
  2. Встав на точке, закройте вкладку конструктора («Закрыть без сохранения», если спросит).
  - Должно быть: в шаге 1 зелёных и синих блоков нет, есть только оранжевая рамка на паузе; в шаге 2 скрипт сам доходит до конца (внизу «Сценарий завершён»), ничего не висит.
