# Тестирование

`just verify` = `cargo fmt --check` + `clippy -D warnings` + `cargo test`. Его запускаем перед каждым PR, CI запускает его же.

## Ручной чек-лист UI

Пункты добавляются по мере появления этапов. Галочку ставит тот, кто проверил руками на своём рабочем столе.

### Этап 1: каркас
- [ ] `cargo run -p shagshell` открывает окно «ShagShell Secure» 1200×800: меню из 9 пунктов, тулбар, Session Manager слева, «Нет открытых сессий» в центре, «Не подключено» внизу
- [ ] В меню активны только Файл → Выход, Вид → Менеджер сессий, Справка → О программе; остальные пункты серые; кнопки тулбара не нажимаются, подсказки показываются
- [ ] Файл → Выход закрывает окно
- [ ] Справка → О программе открывает боковую панель: версия 0.1.0, GPL-3.0-only, ссылки открываются в браузере; панель закрывается крестиком
- [ ] Alt+M (и в русской раскладке) прячет и показывает Session Manager; галочка в Вид → Менеджер сессий меняется вместе с ним; после перезапуска состояние то же
- [ ] Светлая и тёмная тема: всё читаемо
- [ ] `shagshell --check` печатает ok/MISSING для ssh, telnet, picocom, python3; `shagshell --version` → `shagshell 0.1.0`
- [ ] `just deb` → `sudo apt install ./target/deb/shagshell_0.1.0_amd64.deb`: в лаунчере COSMIC есть «ShagShell Secure» с иконкой, запускается; `sudo apt remove shagshell` удаляет

### Этап 2: терминал, вкладки, группы
- [ ] Ctrl+Shift+T (и в русской раскладке) открывает вкладку с локальным shell в домашнем каталоге; вторая — рядом; заголовок — от shell или «Local Shell (2)»
- [ ] В терминале работают Ctrl+C / Ctrl+D / Ctrl+Z / Ctrl+W, Alt+B / Alt+F (readline), стрелки, Tab-дополнение
- [ ] mc, htop, vim рисуются правильно, мышь в mc работает; цвета 256 / true color (`printf '\e[38;2;255;100;0mTRUE\e[0m'`)
- [ ] Ctrl+Tab / Ctrl+Shift+Tab переключают по кругу, Alt+1…9 — на N-ю вкладку; клик по вкладке переключает
- [ ] `exit` → вкладка остаётся с ✗, «[Process exited with code 0 — press Enter to restart]», статус «Отключено»; Enter запускает shell заново (✓)
- [ ] Ctrl+Shift+W / × / средняя кнопка по живой вкладке → диалог «Закрыть вкладку…?»: Отмена оставляет, Закрыть закрывает; завершённая закрывается сразу
- [ ] ПКМ по вкладке → меню Reconnect / Clone / В новую группу справа / снизу / Закрыть; каждое действует на ту вкладку, по которой кликнули
- [ ] Окно → В новую группу справа / снизу: вкладка уходит в новую группу (из группы с одной вкладкой — ничего); разделитель тянется; рамка у активной группы; `stty size` совпадает со статусом после изменения размера окна и разделителя
- [ ] Закрыть последнюю вкладку группы — группа исчезает; последнюю вообще — заглушка
- [ ] Перетаскивание вкладки в полосе меняет порядок
- [ ] Выделение мышью → текст в буфере (вставить в другом приложении); средняя кнопка вставляет; Ctrl+Shift+C / Ctrl+Shift+V; Правка → Копировать / Вставить / Выделить всё
- [ ] Параметры → Общие параметры: переключатели «Копировать при выделении» и «Вставлять средней кнопкой» выключают своё поведение сразу, сохраняются после перезапуска
- [ ] Ctrl+Insert / Shift+Insert приложение не перехватывает
- [ ] Смена светлой / тёмной темы системы — цвета терминала меняются в открытых вкладках

### Этап 3a: сессии, дерево, Quick Connect
- [ ] Дерево из `~/.config/shagshell/sessions/`: папки сверху, по имени; ▸/▾ и двойной клик раскрывают; раскрытые папки и ширина панели — после перезапуска те же
- [ ] Двойной клик по сессии → вкладка ssh с именем сессии; статус «Подключено · SSH · host»; пароль / ключ хоста ssh спрашивает в терминале
- [ ] Ctrl+клик и Shift+клик выделяют несколько; Enter / ▶ / «Подключить» открывают все; выделенная папка — все сессии в ней
- [ ] Фильтр по имени и хосту, папки совпадений раскрыты; «Ничего не найдено»; крестик очищает
- [ ] Перетаскивание сессии / папки на папку (и на пустое место — в корень); в свою подпапку — сообщение, ничего не двигается; занятое имя — сообщение
- [ ] ПКМ по строке: Подключить / Переименовать… / Удалить… / Новая сессия… / Новая папка…; F2 и Delete на выделенной строке
- [ ] Переименование / новая папка: пустое имя, «/», «.x», «Default» в корне, занятое имя — сообщение в диалоге
- [ ] Удаление папки — «вместе с N сессиями»
- [ ] Разделитель панели тянется (160…600), терминал перестраивается
- [ ] Alt+Q → Быстрое подключение; хост обязателен, порт 1…65535; «Сохранить сессию» с именем — файл появился и выделен в дереве (фильтр сброшен)
- [ ] Alt+C показывает Session Manager и ставит курсор в фильтр; Alt+Q / Alt+C из поля фильтра работают (буква при этом попадает в поле — известно)
- [ ] Файл → Импорт из ~/.ssh/config: папка «ssh config» с alias'ами, повторный импорт пропускает существующие; подключение к импортированной сессии берёт HostName/User/ProxyJump из конфига
- [ ] Reconnect вкладки ssh запускает то же подключение; Clone — ещё одно (по ControlMaster без повторного пароля)

### Этап 3b: окно Session Options
- [ ] ПКМ по сессии → «Изменить…» (у папки неактивно), кнопка ✎ над деревом, шестерёнка тулбара / Options → Session Options… (сессия активной вкладки, иначе выделенная) — отдельное окно «Параметры сессии — имя», фокус в поле «Хост»
- [ ] Слева «Подключение» / «SSH2»; поля: хост, порт, пользователь; ключ + «Обзор…» (выбор файла, путь в домашней папке — `~/…`), keepalive, доп. параметры ssh
- [ ] OK / Enter в поле — запись в файл и закрытие; ошибки (пустой хост, порт 0 / 70000, keepalive «10s», незакрытая кавычка) — строкой внизу, окно остаётся
- [ ] Cancel / × / Alt+F4 — ничего не записано
- [ ] «Новая сессия…» (ПКМ, кнопка над деревом) — окно с полем «Имя», поля из Default; OK — файл в той папке, выделен в дереве; занятое / пустое имя — сообщение
- [ ] Options → Edit Default Session… — правка `Default.toml` (нет файла — пустые поля, OK создаёт); хост можно оставить пустым; новая сессия берёт эти значения
- [ ] Повторный вызов при открытом окне поднимает его, введённое не теряется
- [ ] Клавиши в окне параметров не доходят до главного (Alt+Q не открывает Quick Connect, Ctrl+Shift+V не вставляет в терминал)
- [ ] Закрытие главного окна при открытом окне параметров закрывает приложение
- [ ] Сессия переименована / удалена, пока открыто окно → OK пишет ошибку, файла под старым именем не появляется
- [ ] Новые параметры действуют при следующем подключении: из дерева, Reconnect и Clone открытой вкладки (SecureCRT перечитывает сессию)
- [ ] Сессия (или её папка) переименована / перемещена при открытой вкладке → шестерёнка тулбара открывает её под новым именем, Reconnect работает
- [ ] Esc в окне параметров (не в поле) — Отмена; Ctrl, отпущенный в окне параметров, не «залипает» для кликов в дереве
- [ ] Файл в сессии с неизвестными полями (от новой версии / руками) — после OK они остались в файле

### Этап 4a: askpass, keyring, ключ хоста
- [ ] Первое подключение к новому хосту — диалог «Новый ключ хоста — <вкладка>» с отпечатком; «Принять и сохранить» — подключилось, ключ в known_hosts; «Отмена» — вкладка завершилась
- [ ] Сессия с паролем: диалог «Пароль — <вкладка>», вкладка запроса впереди, поле скрывает ввод, «Сохранить пароль» выключено
- [ ] Неверный пароль → тот же диалог с «Пароль не подошёл», поле пустое
- [ ] «Сохранить пароль» + верный → следующее подключение (после закрытия ControlMaster, 60 с) без диалога
- [ ] Сохранён неверный (сменили на сервере) → не три попытки с ним, а диалог «не подошёл»; новый с «Сохранить» заменяет старый
- [ ] «Отмена» в диалоге пароля — ssh завершается сразу, на сервере нет лишних неудачных попыток (`journalctl` / `auth.log`)
- [ ] Session Options сессии с паролем: «Пароль сохранён в keyring» [Забыть]; после «Забыть» пароль снова спрашивается
- [ ] Переименование / перенос сессии (и папки) — сохранённый пароль работает под новым именем; удаление — запись из keyring (Seahorse «Пароли и ключи») пропала
- [ ] Quick Connect без сохранения — диалог пароля без возможности сохранить («только для сохранённой сессии»)
- [ ] Passphrase ключа (ключ не в ssh-agent): диалог «Passphrase ключа», «Сохранить passphrase»
- [ ] Connect all на две сессии с паролем — два диалога по очереди, каждый со своей вкладкой
- [ ] Вкладку закрыли, пока висит её диалог (ssh отвалился по таймауту) — диалог исчез
- [ ] Keyring заблокирован — gnome-keyring спрашивает пароль разблокировки; отказ — диалог пароля работает, «Сохранить» с подсказкой об ошибке
- [ ] `shagshell --check` — строка keyring ok
- [ ] Два запущенных экземпляра — запросы каждого приходят в своё окно
- [ ] Локальный shell: `ssh host` вручную спрашивает пароль в терминале, как обычно (askpass только у сессий)

## Регрессии

| Тест | Что ловит |
|---|---|
| `check::tests::regression_not_executable_is_missing` | `--check` не считает найденной неисполняемую программу |
| `session::store::tests::regression_move_into_own_subfolder` | папку нельзя переместить в саму себя или в свою подпапку |
| `launch::tests::regression_extra_quotes` | кавычки в «Дополнительных параметрах ssh» дают один аргумент |
| `shell::tests::regression_pick_not_executable` | `$SHELL` на неисполняемый файл → `/bin/sh`, а не вкладка, которая не стартует |
| `askpass::tests::regression_cancel_ends_the_connection` | «Отмена» в диалоге пароля завершает ssh, а не отдаёт ему пустой пароль ещё два раза |
