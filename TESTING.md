# Тестирование

`just verify` = `cargo fmt --check` + `clippy -D warnings` + `cargo test`. Его запускаем перед каждым PR, CI запускает его же.

## Ручной чек-лист UI

Пункты добавляются по мере появления этапов. Галочку ставит тот, кто проверил руками на своём рабочем столе.

### Этап 1: каркас
- [ ] `cargo run -p shagshell` открывает окно «ShagShell Secure» 1200×800: меню из 9 пунктов, тулбар, Session Manager слева, «Нет открытых сессий» в центре, «Не подключено» внизу
- [ ] В меню активны только Файл → Выход, Вид → Менеджер сессий, Справка → О программе; остальные пункты серые; кнопки тулбара не нажимаются, подсказки показываются
- [ ] Файл → Выход закрывает окно
- [ ] Справка → О программе открывает боковую панель: версия 0.1.0, GPL-3.0-only, ссылки открываются в браузере; панель закрывается крестиком
- [ ] Alt+M (и в русской раскладке) прячет и показывает Session Manager; галочка в Вид → Менеджер сессий меняется вместе с ним; после перезапуска состояние то же
- [ ] Светлая и тёмная тема: всё читаемо
- [ ] `shagshell --check` печатает ok/MISSING для ssh, telnet, picocom, python3; `shagshell --version` → `shagshell 0.1.0`
- [ ] `just deb` → `sudo apt install ./target/deb/shagshell_0.1.0_amd64.deb`: в лаунчере COSMIC есть «ShagShell Secure» с иконкой, запускается; `sudo apt remove shagshell` удаляет

### Этап 2: терминал, вкладки, группы
- [ ] Ctrl+Shift+T (и в русской раскладке) открывает вкладку с локальным shell в домашнем каталоге; вторая — рядом; заголовок — от shell или «Local Shell (2)»
- [ ] В терминале работают Ctrl+C / Ctrl+D / Ctrl+Z / Ctrl+W, Alt+B / Alt+F (readline), стрелки, Tab-дополнение
- [ ] mc, htop, vim рисуются правильно, мышь в mc работает; цвета 256 / true color (`printf '\e[38;2;255;100;0mTRUE\e[0m'`)
- [ ] Ctrl+Tab / Ctrl+Shift+Tab переключают по кругу, Alt+1…9 — на N-ю вкладку; клик по вкладке переключает
- [ ] `exit` → вкладка остаётся с ✗, «[Process exited with code 0 — press Enter to restart]», статус «Отключено»; Enter запускает shell заново (✓)
- [ ] Ctrl+Shift+W / × / средняя кнопка по живой вкладке → диалог «Закрыть вкладку…?»: Отмена оставляет, Закрыть закрывает; завершённая закрывается сразу
- [ ] ПКМ по вкладке → меню Reconnect / Clone / В новую группу справа / снизу / Закрыть; каждое действует на ту вкладку, по которой кликнули
- [ ] Окно → В новую группу справа / снизу: вкладка уходит в новую группу (из группы с одной вкладкой — ничего); разделитель тянется; рамка у активной группы; `stty size` совпадает со статусом после изменения размера окна и разделителя
- [ ] Закрыть последнюю вкладку группы — группа исчезает; последнюю вообще — заглушка
- [ ] Перетаскивание вкладки в полосе меняет порядок
- [ ] Выделение мышью → текст в буфере (вставить в другом приложении); средняя кнопка вставляет; Ctrl+Shift+C / Ctrl+Shift+V; Правка → Копировать / Вставить / Выделить всё
- [ ] Параметры → Общие параметры: переключатели «Копировать при выделении» и «Вставлять средней кнопкой» выключают своё поведение сразу, сохраняются после перезапуска
- [ ] Ctrl+Insert / Shift+Insert приложение не перехватывает
- [ ] Смена светлой / тёмной темы системы — цвета терминала меняются в открытых вкладках

## Регрессии

| Тест | Что ловит |
|---|---|
| `check::tests::regression_not_executable_is_missing` | `--check` не считает найденной неисполняемую программу |
| `shell::tests::regression_pick_not_executable` | `$SHELL` на неисполняемый файл → `/bin/sh`, а не вкладка, которая не стартует |
