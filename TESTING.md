# Тестирование

`just verify` = `cargo fmt --check` + `clippy -D warnings` + `cargo test`. Его запускаем перед каждым PR, CI запускает его же.

## Ручной чек-лист UI

Пункты добавляются по мере появления этапов. Галочку ставит тот, кто проверил руками на своём рабочем столе.

## Регрессии

| Тест | Что ловит |
|---|---|
| `check::tests::regression_not_executable_is_missing` | `--check` не считает найденной неисполняемую программу |
| `session::store::tests::regression_move_into_own_subfolder` | папку нельзя переместить в саму себя или в свою подпапку |
| `launch::tests::regression_extra_quotes` | кавычки в «Дополнительных параметрах ssh» дают один аргумент |
| `shell::tests::regression_pick_not_executable` | `$SHELL` на неисполняемый файл → `/bin/sh`, а не вкладка, которая не стартует |
| `askpass::tests::regression_cancel_ends_the_connection` | «Отмена» в диалоге пароля завершает ssh, а не отдаёт ему пустой пароль ещё два раза |
| `askpass::tests::regression_jump_ssh_is_not_direct` | ssh до jump-хоста (`-J` / ProxyJump) не получает и не перезаписывает сохранённый пароль сессии |
| `askpass::tests::regression_reused_pid_starts_afresh` | новый ssh с pid завершённого не наследует его «отменено» / «уже отвечали» |
| `sftp::proto::tests::list_non_utf8_names` | имя файла не в UTF-8 на сервере не рвёт SFTP-соединение (было в `openssh-sftp-client`) |
| `sftp::proto::tests::regression_local_failure_keeps_the_stream_in_step` | локальная ошибка посреди передачи (диск полон) не сбивает ответы SFTP следующих команд |
| `sftp::ops::tests::regression_failed_overwrite_keeps_the_original` | неудачная / отменённая перезапись (в обе стороны) оставляет прежний файл, без `.part` |
